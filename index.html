1 Votre profil

Je n’ai pas de coordonnées G25

Le Global25 n’est pas un test : c’est une projection calculée à partir d’un fichier de données brutes déjà existant (23andMe, MyHeritage, FTDNA, Ancestry…). On obtient une ligne de 25 nombres, au format Nom,PC1,…,PC25.

Deux variantes circulent : scaled et non scaled. Cet outil attend la version scaled, la même que sa base — mélanger les deux fausse toutes les distances.

En attendant, les boutons d’exemple ci-dessus chargent un profil réel du jeu sélectionné : de quoi voir ce que produit l’outil avant d’y mettre le vôtre.

Comparer deux profils

Collez un second profil : la carte affiche alors l’écart entre les deux. Bleu où le profil A est le plus proche, rouge où c’est le profil B. Utile pour deux parents, deux branches, ou soi-même contre un ancêtre reconstitué.

Filtrer les échantillons

Un échantillon (n=1) est un individu, pas une population. Le monter à 3 ou 5 écarte le plus gros du bruit.

Apparence de la carte

procheloin

Remplace les aplats par un dégradé continu, calculé entre les points. Les frontières administratives n’ont aucune réalité génétique ; le point d’un échantillon est le centre de son territoire, pas son lieu de fouille.

Sans cette option, un territoire sans échantillon reste gris. Avec, il prend la valeur de son pays — la même pour toutes ses subdivisions : la carte se remplit, mais une région non documentée y paraît aussi proche que la mieux documentée. Ces territoires sont hachurés.

Modélisation (admixture)

La carte dit de quelle population vous êtes le plus proche. Le modèle dit de quoi vous êtes composé — la bonne question dès qu’un profil est un mélange. Il n’utilise que les échantillons laissés par vos filtres.
